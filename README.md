# TG-bot horoscopes
Телеграмм бот для рассылки гороскоп из готового файла json.
![[Снимок экрана 2026-09-20 124522.png]]

скачать его можно через
```
git clone [ссылка на репозиторий]

BOT_TOKEN=1222:fefsfbvsbsd в env измените на свой tg-bot token
# Ссылка на ваш канал (латиницей, например https://t.me/my_channel)
CHANNEL_URL=https://web.telegram.org
# Время утренней рассылки (ЧЧ:ММ) и часовой пояс
#Устанавливать время рассылки
SEND_TIME=09:00
#time zone можно взять из сайта https://www.zeitverschiebung.net/en/timezone/europe--moscow
TIMEZONE=Europe/Moscow

и также ссылка на ваш канал


```
